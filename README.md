# Design Asset Board

个人本地设计素材整理工具。用于保存图片素材、软件内文件夹分类、高清查看、无限画板整理参考图，并支持基础备注。

## 功能

- 复制粘贴图片到软件内素材库
- 软件内文件夹分类，支持多层级文件夹
- 图片高清查看和右侧信息面板
- 无限画板，支持图片移动、缩放、旋转、复制粘贴、拖出悬浮窗口
- 回收站和主题设置
- 本地保存，不依赖云同步

## 启动

```bash
npm install
npm start
```
